## 🌟 Core Platform Capabilities

### 1. Three Switchable Design Concepts (Instant Zero-Reload Theme Engine)
Customers and shop staff can switch live between three distinct industrial visual aesthetics tailored to 910 PrintShop's core buyer personas:
- **🏎️ Concept 1 — `Garage Carbon` (Default):** Matte carbon-fiber obsidian (`#0A0B0E`), high-visibility wrap safety cyan (`#00E5FF`), and laser magenta (`#FF2A85`) engineered for commercial fleet managers, exotic color-change wrap clients, and food trailer owners.
- **🪖 Concept 2 — `Vinyl & Sticker Lab`:** Airborne olive drab (`#0F130E`), tactical Coyote tan, and Fort Bragg amber gold (`#F59E0B`) honoring 910 PrintShop's Veteran-Owned roots along the Bragg Blvd corridor and tailored for military unit PT shirts, deployment hoodies, and brigade morale gear.
- **🎨 Concept 3 — `Print Studio`:** High-precision CMYK registration dark slate (`#0D0E12`) with cyan, magenta, yellow, and key-black press accents showcasing wide-format banners, die-cut decals, and storefront signage.

### 2. Interactive Wrap & Print Quote Estimator
Replaces slow "wait 3 days for a quote" forms with an instant, transparent line-item estimator across all four production departments:
- **Commercial Vehicle Wraps & Fleet Graphics:** Full Cast Wraps, Partial Fleet Wraps, Color-Change Wraps, Perforated Rear Window Graphics (60/40), and USDOT / Door Logo Lettering across Cargo Vans, Pickup Trucks, Box Trucks (16ft–26ft), Food Trailers, and Sedans/SUVs.
- **Custom Apparel (DTF & Screen Print):** Bulk volume discount tiers (`12+`, `24+`, `50+`, `100+` units) for Heavyweight Cotton Tees, Fort Bragg Unit PT Performance Shirts, Tactical Hoodies, and Embroidered Polos.
- **Custom Die-Cut Decals & Stickers:** UV-laminated cast vinyl stickers, hard-hat decals, and military unit morale slaps.
- **Commercial Signage & Banners:** 13oz/18oz Heavy-Duty Vinyl Banners, Coroplast Yard Signs (with H-stakes), and MaxMetal Aluminum Storefront Signs.
- **Automated NC Tax & 1-Tap Dispatch:** Automatically calculates **7.00% Cumberland County, NC Sales Tax** (4.75% NC State + 2.25% County), optional 48-hour rush production fees, and dispatches the itemized quote directly to **(910) 920-0863** via 1-tap Call or formatted SMS.

### 3. Showroom 55" 1080p TV Board + Digital Twin Simulator
- Designed to run full-screen on a wall-mounted **55-inch 1080p TV** behind the front counter at **4315 Bragg Blvd**.
- Includes an interactive **Digital Twin Simulator** allowing walk-in customers and shop staff to preview live pricing packages, wrap bay queue status, contractor bundles (*Truck Wrap + 25 Crew Tees + 20 Yard Signs*), and Fort Bragg unit specials in high-contrast 16:9 widescreen format.

### 4. 10-Second Shop Owner Quick-Admin
- Accessible right from the shop owner's phone or counter tablet without touching code or complex CMS backends:
  - **Live Wrap Bay Status Toggle:** Instantly switch between *"Bay Open — Booking This Week"*, *"Booking Next Week"*, or *"Fleet Queue Active"*.
  - **Rush Press Toggle:** Enable or pause *24–48hr Rush Apparel & Banner Turnaround* based on daily press capacity.
  - **Live Shop Promo Banner & Package Toggles:** Update active Bragg Blvd / Fort Bragg specials and persist states instantaneously in browser storage.

## 🚀 Local Setup & Build Instructions

### Prerequisites
- **Node.js** `v18.0.0+` (or `v20+` LTS recommended)
- **npm** `v9+`

### Installation & Commands

```bash
# 1. Clone the repository
git clone https://github.com/Reign3418/910printshop.git
cd 910printshop

# 2. Install dependencies
npm install

# 3. Start local development server with hot-reload
npm run dev

# 4. Run TypeScript typecheck & production build
npm run build

# 5. Preview production build locally
npm run preview
```
